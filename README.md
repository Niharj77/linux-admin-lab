
# Linux Administration & DevOps Lab

A hands-on Linux administration project built using Ubuntu, WSL, Bash scripting, and PowerShell.

## Modules

1. System Information
2. Disk Monitoring
3. Process Monitoring
4. Network Diagnostics
5. Linux File Permissions
6. Log Management
7. Bash Automation

## Technologies

- Ubuntu Linux
- Windows WSL
- Bash
- PowerShell
- Visual Studio Code
- Git & GitHub

## Purpose

To practice real-world Linux administration and DevOps troubleshooting skills through practical scripts and exercises.
